Hasamex Expert Call Intelligence Assistant



A Streamlit-based Retrieval-Augmented Generation (RAG) application that analyzes expert-call transcripts from the European robotic surgery market.



The application analyzes calls from France, Germany, and the United Kingdom. It helps users answer the provided interview guide, verify findings with exact source evidence and timestamps, compare expert perspectives, and ask questions across the transcripts.



\---



Features



\- Answers the six interview-guide questions using transcript evidence.

\- Extracts and displays exact expert quotes.

\- Shows country, expert name, source filename, and original timestamp for every displayed evidence item.

\- Identifies common themes, country-specific differences, and uncertainty across all three expert calls.

\- Supports free-text questions across all transcripts.

\- Includes a country filter for France, Germany, the United Kingdom, or all countries.

\- Uses retrieval-augmented generation to reduce unsupported answers.



\---



Case Requirements Covered



| Requirement | Implementation |

|---|---|

| Answer the interview guide | Users select any of the six interview-guide questions in the application. |

| Extract exact quotes | Expert responses are retained from the source transcripts and displayed as evidence. |

| Show timestamps | Every evidence card displays the original source timestamp. |

| Compare calls | The cross-call analysis compares all parsed expert responses from France, Germany, and the United Kingdom. |

| Ask questions across transcripts | Users can ask free-text questions and retrieve relevant evidence. |

| Prevent unsupported answers | The language model is instructed to use only the supplied transcript evidence. |

\## Architecture



```text

Raw Transcript Files

      |
      v

Transcript Parser

      |
      v

Structured Evidence Records

(country, expert, role, timestamp, question, answer, source file)

      |
      v

SentenceTransformer Embeddings

      |
      v

FAISS Vector Search

      |
      v

Relevant Evidence Chunks

      |
      v

Groq LLM Grounded Answer Generation

      |
      v

Streamlit Interface + Source Evidence Cards

```



1. Transcript parsing



The parser reads the supplied transcript files and converts each expert response into a structured record.



Each record preserves:



\- Country

\- Expert name

\- Expert role

\- Original timestamp

\- Interviewer question

\- Exact expert response

\- Source filename



This metadata makes every generated answer traceable to the source transcript.



2. Retrieval



The application uses the `all-MiniLM-L6-v2` SentenceTransformer model to create vector embeddings for transcript question-and-answer records.



FAISS performs semantic similarity search to retrieve the most relevant evidence for the user’s question.



3. Grounded generation



The retrieved transcript chunks are sent to Groq with strict instructions to:



\- Use only the provided transcript evidence.

\- Avoid inventing facts, quotes, timestamps, countries, or speakers.

\- State when evidence is insufficient.

\- Include citations in this format:



```text

\[Country | Expert Name | MM:SS]

```



4. Evidence verification



The Streamlit interface displays the exact supporting transcript response below each generated answer. Every evidence card includes the country, expert, timestamp, original quote, and source file.



\---



Hallucination Controls



This project reduces hallucinations through several safeguards:



\- The language model receives only retrieved transcript evidence.

\- Prompt instructions prohibit using outside knowledge.

\- Timestamps are parsed directly from source transcripts, not generated by the model.

\- The interface displays original evidence for user verification.

\- Country-specific filtering is applied before retrieval to prevent unrelated country evidence appearing in focused searches.

\- The cross-call analysis uses all available structured transcript records.



\---



Scaling to 30+ Transcripts



To extend this prototype to a larger production dataset, the following improvements can be added:



\- Automated transcript upload and ingestion pipeline.

\- Persistent FAISS index or a managed vector database such as ChromaDB, Pinecone, or Weaviate.

\- Metadata filtering by country, sector, project, expert role, and call date.

\- Hybrid retrieval using semantic search plus keyword search.

\- Reranking of retrieved chunks for higher relevance.

\- Automated evaluation for retrieval quality, citation correctness, and answer grounding.

\- Authentication, access controls, logging, and monitoring.

Installation and Setup



1. Clone the repository



```bash

git clone \[https://github.com/YOUR\_GITHUB\_USERNAME/hasamex-expert-call-intelligence.git](https://github.com/YOUR\_GITHUB\_USERNAME/hasamex-expert-call-intelligence.git)

cd hasamex-expert-call-intelligence

```



\### 2. Create a virtual environment



Windows PowerShell:



```powershell

python -m venv venv

.\\venv\\Scripts\\Activate.ps1

```



If PowerShell blocks script activation, run:



```powershell

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

```



Then run the activation command again:



```powershell

.\\venv\\Scripts\\Activate.ps1

```



3. Install dependencies



```powershell

pip install -r requirements.txt

```



4. Configure the Groq API key



Create a `.env` file in the root folder:



```text

GROQ\_API\_KEY=your\_groq\_api\_key\_here

```



Do not upload the `.env` file to GitHub.



5. Add transcript files



Place these three supplied transcript files in:



```text

data/raw/

```



Required filenames:



```text

Transcript\_1\_France.txt

Transcript\_2\_Germany.txt

Transcript\_3\_UK.txt

```



6. Run the application



```powershell

streamlit run app.py

```



Open the local URL shown in the terminal, normally:



```text

http://localhost:8501

```

How to Use the Application



Interview Guide



1\. Open the \*\*Interview Guide\*\* tab.

2\. Select one of the provided interview questions.

3\. Click \*\*Generate Answer\*\*.

4\. Review the grounded answer and its source evidence cards.



Cross-Call Themes



1\. Open the \*\*Cross-Call Themes\*\* tab.

2\. Click \*\*Generate Theme Analysis\*\*.

3\. Review common themes, market-specific differences, and uncertainty across all calls.



Ask Across Transcripts



1\. Open the \*\*Ask Across Transcripts\*\* tab.

2\. Select a country scope or choose \*\*All countries\*\*.

3\. Enter a question.

4\. Click \*\*Ask\*\*.

5\. Review the answer and supporting evidence.
